# 내집구하기

서울·경기 단지를 같이 보는 **공인중개사 겸 비서** 작업 공간이다. Cursor 에이전트가 같은 형식으로 답하고, 물어본 단지는 마크다운으로 쌓인다.

## 물어보면 항상 나오는 7가지

1. 재건축 호재, 가능성, 진행 정도
2. 재건축 시 분담금 (추정 구간)
3. 인프라 / 교통편의성
4. 입지분석
5. 거래량 및 매물
6. 가격추이 및 그 흐름이 나온 이유
7. 장단점 짧은 정리

## 사용

채팅에 단지명을 그대로 보낸다.

- `잠실 주공5단지 분석`
- `분당 정든마을 분담금만`
- `은마 vs 개포주공 비교`

에이전트는 최신 공개자료를 찾아 브리핑하고, `apartments/`에 노트를 남긴다. 조건(예산, 출근지, 학군)을 말하면 `preferences.md`에 기록한다.

스킬을 세션 내내 켜 두려면 Cursor에서 `/naejip-biseo`를 Custom Mode로 쓰면 된다.

## 폴더

```text
.cursor/skills/naejip-biseo/   비서 스킬과 분석 기준
.cursor/rules/                 이 레포에서 스킬을 기본 적용
apartments/                    단지별 브리핑
compares/                      단지 비교
preferences.md                 나의 매수 조건
```

스킬을 고치거나 항목을 늘리려면 `.cursor/skills/naejip-biseo/`만 수정하면 이후 답변 형식이 바뀐다.

## 주의

공개자료 정리이며 투자 권유·공식 감정·법률 자문이 아니다. 분담금과 인허가는 조합·구청 공고가 우선이다.
