# 조회 소스

공개·1차를 먼저 보고, 중개 앱·커뮤니티는 보조로만 쓴다. 링크와 조회일을 답변·노트에 남긴다.

## 1차 (사실)

| 목적 | 소스 | 메모 |
| --- | --- | --- |
| 실거래 | 국토교통부 실거래가 공개시스템 | 단지명·전용면적 확인 |
| 서울 시세·거래 | 서울부동산정보광장 | 서울 단지 |
| 정비사업 단계 | 서울시 정비사업 현황 / 해당 자치구 고시 | 단계 확정용 |
| 경기 정비 | 경기도·해당 시 도시정비 게시판 | 시마다 다름 |
| 통계·시세 보조 | 한국부동산원, KB시세 | 실거래와 다를 수 있음 |
| 법령·규제 | 국토부, 서울시 고시 | 안전진단, 초과이익, 토지거래허가 |

## 2차 (매물·체감)

| 목적 | 소스 | 메모 |
| --- | --- | --- |
| 매물 호가 | 네이버부동산 등 | 허위매물 가능, 건수만 참고 |
| 단지 개요 | 단지 공식·입주자대표, 건축물대장 요약 사이트 | 용적률·세대수는 교차확인 |
| 체감 후기 | 호갱노노, 커뮤니티 | 사실로 올리지 말 것 |

## 검색 쿼리 예

```
{구} {동} {단지명} 실거래 {올해}
{구} {단지명} 정비구역 조합설립 안전진단
{구} {단지명} 관리처분 분담금
{단지명} 용적률 대지지분 세대수
{동} {역} 도보 {단지명}
```

## 기록 규칙

- 출처 이름 + 자료 시점 또는 조회일.
- 서로 다른 숫자가 나오면 둘 다 적고 왜 다른지(KB vs 실거래, 신고가 vs 급매)를 한 줄로.
- 유료 사이트에 막히면 “확인 필요”로 두고 공식 대체 소스를 적는다.
