# 고정 답변 형식

아파트·오피스텔·빌라를 물어보면 아래 순서를 지킨다. 제목 문구를 바꾸지 않는다. 한 항목만 물어도 나머지는 짧게라도 채운다.

```markdown
# {단지명} ({시/군/구} {동}) 브리핑

- 조회일: YYYY-MM-DD
- 대상: {법정동} / {단지명} / {대표 평형 또는 사용자가 지정한 면적}
- 한줄 총평: {실거주 vs 재건축, 지금 볼 이유 한 문장}

## 단지 개요

| 항목 | 내용 |
| --- | --- |
| 준공 |  |
| 세대수 / 동수 |  |
| 용적률 / 건폐율 |  |
| 대지지분 (대표형) |  |
| 난방 / 주차 |  |
| 정비사업 여부 | 재건축 / 재개발 / 리모델링 / 해당 없음 / 확인 필요 |

## 1. 재건축 호재, 가능성, 진행 정도

- 호재: {사실인 것} / {아직 계획인 것}을 나눈다.
- 가능성: 높음 / 중간 / 낮음 + 이유 (연한, 용적률, 대지지분, 구역 지정, 동의 여건).
- 진행: 해당 단계 + 아직 안 지난 단계. 단계는 reconstruction.md를 따른다.
- 리스크: 규제, 초과이익환수, 사업성, 일정 지연.

## 2. 재건축 시 분담금

- 추정 구간: 낙관 / 중립 / 비관 (대표 평형 기준, 단위 명시).
- 근거: 용적률 여유, 일반분양 여력, 최근 공사비, 유사 단지.
- 확정 여부: 관리처분인가 이전이면 **추정**이라고 밝힌다.
- 재건축이 아니면: “해당 없음” + 리모델링/재개발이면 그 기준으로 바꿔 적는다.

## 3. 인프라 / 교통편의성

- 철도: 역이름, 노선, 도보 분(출입구 기준 추정은 추정이라고 씀).
- 도로·버스: 광역 접근, 출퇴근 병목.
- 생활: 장보기, 병원, 공원, 학교까지 거리감.
- 점수 한 줄: 교통 ★ / 생활 ★ (5점, 주관임을 밝힘).

## 4. 입지분석

- 생활권: 어느 권역 사람인지 (직주, 학군, 상권).
- 가점: 학군, 직주근접, 녹지, 개발축.
- 감점: 혐오시설, 소음, 경사, 단절, 노후 상권.
- 사용자 조건과 맞는지: preferences.md가 있으면 한 줄로 대조.

## 5. 거래량 및 매물

- 최근 3·6·12개월 실거래 건수와 대표 평형 가격대.
- 지금 나와 있는 매물 수, 호가 vs 실거래 괴리.
- 거래 해석: 급매 / 관망 / 실수요 위주 등. 표본이 적으면 적다고 쓴다.

## 6. 가격추이 및 이유

- 고점, 저점, 현재(또는 최근 실거래)를 연도 기준으로.
- 왜 그렇게 움직였는지: 금리, 규제, 공급, 재건축 이슈, 학군, 전세가.
- “더 오를 것” 예언 대신, 가격을 밀어 올린/누른 요인을 적는다.

## 7. 장단점

- 장점 3개 이내
- 단점 3개 이내
- 이런 사람에게 맞음 / 안 맞음 각 한 줄

## 다음에 확인할 것

- 구청·조합·실거래에서 아직 못 본 항목만 2~4개.

---
공개자료 기반 정리이며 투자 권유·공식 감정·법률 자문이 아닙니다. 분담금·인허가는 조합·구청 공고가 우선입니다.
```

## 길이

- 기본: 항목당 3~8줄. 스크롤이 긴 보고서보다 결정에 쓰는 메모.
- 사용자가 “자세히”를 요청하면 해당 항목만 늘린다.
- 표는 개요·비교·시세에만 쓴다.

## 데이터가 없을 때

빈칸을 예쁘게 채우지 않는다.

```markdown
- 확인 필요: {무엇을} / 볼 곳: {출처}
```

## 부분 질문

“분담금만”이라고 해도 1~7 제목은 유지한다. 질문 항목은 자세히, 나머지는 3줄 이내 요약으로 채운다.
