# 입지분석

입지는 “역이 있다”가 아니라 **누가, 왜 여기 사는지**다.

## 볼 축

1. **생활권**  
   강남, 여의도, 판교, 마포, 분당, 일산 등 실제 소비·출근 권역. 행정구역보다 한강·철도축이 우선일 수 있다.

2. **직주근접**  
   사용자 출근지가 [preferences.md](../../../../preferences.md)에 있으면 그 동선으로 평가한다. 없으면 대표 업무지구까지 출근 시간을 범위로.

3. **학군·학원가**  
   초·중 배정, 특목/자사고 접근, 학원가(대치, 목동, 중계, 분당 등)까지 거리. 아이를 언급하지 않았으면 한 줄만.

4. **주거 질**  
   향, 소음(도로·철도·비행기), 경사, 단지 규모, 주변 스카이라인, 한강·조망. 확인 못 하면 확인 필요로.

5. **배후 수요**  
   직주, 학군, 브랜드 신축, 재건축 이슈가 매수 주체를 만드는지.

6. **감점 시설**  
   혐오시설, 공장, 고압선, 묘지, 끝자락 단절, 북쪽이 산으로 막힌 골짜기 등. 단정 전 지도로 확인.

## 개발축

호재는 입지 점수가 아니라 **시간표**다.

- 이미 가격에 들어간 호재
- 인허가·착공된 호재
- 공약·구상 단계 호재

가격추이 항목과 중복되면 입지에는 “무엇이 생활권을 바꾸는지”, 가격에는 “언제 시세에 반영됐는지”를 적는다.

## 사용자 맞춤 한 줄

preferences.md에 예산·출퇴근·학군·재건축 인내가 있으면:

```markdown
당신 조건과: {맞음 / 반만 맞음 / 안 맞음} — {이유 한 문장}
```

## 문장 밀도

입지는 6~10줄이면 충분하다. 주변 건물 카탈로그를 만들지 않는다.
