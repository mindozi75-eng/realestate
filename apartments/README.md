# 단지 노트

서울·경기에서 물어본 단지의 브리핑을 쌓는 폴더다.

## 쓰는 법

1. 채팅에 단지명을 말한다. 예: `대치 은마 84 분석해줘`
2. 에이전트가 7개 고정 항목으로 답하고, 이 폴더에 노트를 만들거나 고친다.
3. 같은 단지를 다시 물으면 기존 노트를 읽고 숫자만 최신으로 바꾼다.

## 파일

| 파일 | 역할 |
| --- | --- |
| [_index.md](_index.md) | 단지 카탈로그 |
| [_template.md](_template.md) | 파일명 규칙 |
| `{지역}-{동}-{단지}.md` | 단지별 브리핑 |

노트의 칸은 스킬 템플릿과 같다. 빈칸은 비워 두고 “확인 필요”만 적는다.
